## 一、游戏概述

### 1.1 一句话定位

《Subnet：暗流》是一款 7 人实值竞技博弈游戏。玩家以 TAO 质押入场，在倒计时压力下通过数据声明、情报侦查、审计核查、合约投票等行动竞争排名。**局内筹码的每一分变动都指向终局的真实 TAO 收益——有人拿走奖池大头，有人质押清零。**

> 📝 V4.3 修订版变更：审计分层（浅/深审计）；AI 分析收窄为 risk_score 输出（不参与裁判）；commit-reveal 可选机制；数据导出对齐 evidence pack 格式。

### 1.2 核心设计原则

1. **博弈可计算**。矿工知道真实质量，虚报 = 用 TAO 质押换排名提升机会。验证者有线索，举报 = 用筹码买情报。
2. **每次行动都有反馈**。审计抓到虚报 → 全员广播。排名揭晓 → 动画。终局 → 逐人揭示收益。
3. **实值货币驱动**。入场即是质押 TAO。你的每一步决策都在影响你的投资回报率。
4. **原生线上**。无 DM。系统自动推进阶段、管理倒计时、分配收益。

### 1.3 游戏参数

| 项目 | DEMO 值（模拟 TAO） | 正式版 |
|------|-------------------|--------|
| 人数 | 7 人 | 7 人 |
| 时长 | 约 35-50 分钟，共 3 轮 | 同 |
| 入场质押 | 每人 0.05 模拟 TAO | 每人 0.05 TAO（DAO 可调） |
| 收益池 | 0.35 模拟 TAO（7 × 0.05） | 0.35 TAO + 外部 API 收入注入 |
| 初始筹码 | 每人 15 筹码 | 同（筹码 = 局内操作货币） |
| 所有者运营津贴 | 1 筹码 / 轮 | 同 |
| 公共池 | 14 筹码（每人上缴 2） | 同 |
| 叛徒秘密基金 | 6 筹码（系统管理） | 同 |
| 国库抽水 | 收益池 5% | 5% TAO（协议费，归子网国库） |

### 1.4 筹码与 TAO 的关系

局内「筹码」是游戏操作货币——用于审计、举报、交易。终局时，筹码**不直接兑换 TAO**。TAO 收益按**终局排名**从收益池中阶梯分配。

```
局内筹码 = 你的操作资源（用来审计、举报、排名竞争）
终局排名 = 你的操作结果（筹码最多的未必是冠军——要看终局阶梯）
TAO 收益 = 入场质押的回报（收益率取决于你的排名）
```

**举例**：你质押 0.05 TAO 入场。终局排名第 1 → 分得收益池 35% = 0.1225 TAO。你的 ROI = (0.1225 − 0.05) / 0.05 = **+145%**。终局排名第 7 → 收益 0。你的 ROI = **−100%**。

## 二、角色目标与策略空间

### 2.1 子网所有者

**你的身份**：裁判，但你有薪资和奖金。你的收入 = 每轮津贴 + 审计证实收益 + 终局收益分成。

| 优先 | 目标 | TAO 影响 |
|------|------|---------|
| 🔴 必须 | 推动合约达成 | 合约达成 → 你终局排名升一档（若你在第 3 名，等效第 2 名分账） |
| 🟡 重要 | 审计抓到虚报 | 每次证实 → 净赚 1 筹码 + 投票权重 +0.1 |
| 🟢 锦上添花 | 公共目标达成 | 收益池 +10%（外部奖励） |
| 🟢 锦上添花 | 抓出合谋验证者 | 罚没中分得 3 筹码 |

**投资逻辑**：你质押 0.05 TAO 入场。你的审计和踢出决策直接左右合约能否达成 → 影响你的最终排名档位 → 影响你的投资回报率。

### 2.2 验证者

**你的身份**：侦探。你的超额 TAO 回报来自精准举报。

| 优先 | 目标 |
|------|------|
| 🔴 必须 | 精准举报（成功 = 净赚 3 筹码 → 提升排名 → 更高 TAO 分账） |
| 🟡 重要 | 精准评分 |
| 🔴 底线 | 避免合谋标记（罚 5 筹码 → 排名暴跌 → TAO 收益蒸发） |

**投资逻辑**：排名第 6-7 可能拿不回入场质押。你必须通过精准举报 → 净赚筹码 → 推高排名 → 进入前 5 安全区。

### 2.3 矿工（非叛徒）

**你的核心问题**：这个风险值不值得我质押的 0.05 TAO？

| 优先 | 目标 |
|------|------|
| 🔴 必须 | 排名第 1-3 → 拿回超过入场质押的 TAO |
| 🟡 重要 | 管理虚报风险（罚 3 筹码 = 排名下滑 = TAO 收益减损） |

**投资逻辑**：如果"永远诚实"意味着排名第 6-7 → 质押清零 → 那诚实就不如冒险。如果虚报被抓 → 排名暴跌 → 同样清零 → 那冒险不如诚实。你的敌人不是系统——是其他 3 名矿工。你只需要比他们更聪明就够。

### 2.4 叛徒矿工

**你的投资逻辑**：你的 0.05 TAO 质押和其他矿工一样。但你有一条**额外的收益路径**——通过收编操控排名，让自己登上第 1 名。风险：被揭露 → 罚 5 筹码 + 终局排名降两档 → TAO 收益几乎必然清零。

## 五、核心机制速览

### 5.1 矿工虚报与罚款（三级惩罚）

```
系统告知矿工真实质量
          │
          ▼
矿工决定声明星数
    ├─ 声明 ≤ 真实 ──→ 诚实（零风险）
    └─ 声明 > 真实 ──→ 虚报
          │
          ▼
   【浅审计（揭示质量）】→ 揭示但不罚款（仅记录）
   【深审计（揭示+惩罚）】→ 罚 3 筹码 + 全员广播
   【仅终局揭示暴露】→ 罚 1 筹码
   【终局深度审计】  → 升级至 3 筹码 + 可被踢出
```

### 5.2 验证者举报

```
支付 1 筹码举报
    ├── 本轮审计证实 → 返还 4 筹码（净赚 3）
    └── 未证实 → 损失 1 筹码
```

举报在审计阶段核实，不在终局。举报的价值在举报的当下。

### 5.3 终局揭示 vs 深度审计

```
终局 → 系统自动「真相揭示」→ 公开 3 轮全部真实 + 声明
     → 揭示惩罚：逃逸 + 第 3 轮虚报 → 1 筹码/次
     → 所有者可选深度审计 0-4 人（1 筹码/矿工）
     → 深度审计证实 → 升级至 3 筹码 + 可踢出
```

### 5.4 每轮分配

```
公共池支出 6 筹码
  矿工 70%（4.2），排名 50/25/15/10
  验证者 30%（1.8），按所有者预设权重
  公共池不足 → 等比缩减（最低 = 0）
```

### 5.5 合约投票

- 资格：所有存活玩家
- 权重：所有者 = `0.5 + 0.1 × 证实次数 + 0.2（公开报告）`（上限 1.0）；其余 = 1.0
- 通过：**赞成 ＞ 总有效票数 × 2/3**

## 六、完整游戏流程

### 阶段 0：游戏初始化（~30 秒）

1. 7 人满员 → 系统扣除每人 0.05 TAO 入场质押 → 收益池 = 0.35 TAO + 外部 API 当日注入
2. 每人 15 初始筹码。所有者额外 3 津贴。
3. 每人上缴 2 筹码 → 公共池 = 14。
4. 系统生成矿工真实质量 → 单独推送。
5. 所有者设定分配权重 + 公共目标。

### 三轮常规流程（每轮 ~10-15 分钟）

**步骤 1：矿工声明（120 秒倒计时）**
- 矿工界面：真实质量 + 星数选择器 + 提交。超时 → 系统随机声明。
- 其他角色：`⏳ 矿工正在提交... 剩余 XX 秒`

**步骤 2：验证者侦查 + 评分 + 举报（180 秒倒计时）**
- 系统单独推送线索 → 验证者打分（不得全员同分）+ 可选举报
- 超时 → 系统随机打分（非全员同分）

**步骤 3：所有者审计 + 大模型（120 秒倒计时）**
- 审计证实 → 全员广播 + 执行罚款 + 核实举报
- 超时 → 跳过审计

**步骤 4：轮次分配（系统自动）**
- 计算排名 → 6 筹码分配 → 高光推送

**步骤 5：匿名交易（120 秒倒计时）**
- 聊天面板 + 叛徒契约表单

**步骤 6：轮次结算 → 若 round=3 → 终局**

### 终局阶段

**A. 真相揭示** → 公开 3 轮全部 → 揭示惩罚

**B. 深度审计** → 所有者可选 0-4 人（1 筹码/矿工）

**C. 踢出玩家** → 被踢出者丧失 TAO 收益资格

**D. 合谋检测** → 给虚报矿工打高分(>70)且未举报 → 标记合谋 → 罚 5

**E. 合约投票（90 秒）** → 超时默认"反对"

**F. 终局结算 + TAO 收益揭晓动画**（见第七章）

## 八、收益系统

### 8.1 收益池构成

```
收益池 = 玩家入场质押总和 + 外部 API 收入注入

玩家入场质押：0.05 TAO × 7 = 0.35 TAO（固定）
外部 API 注入：当日 Undercurrent 子网 API 调用收入的 X%（DAO 决定，默认 10%）
```

DEMO 阶段：外部 API 注入 = 0（模拟），收益池 = 0.35 模拟 TAO。

### 8.2 收益分配流程

```
终局排名确定
      │
      ▼
系统扣取 5% 国库协议费
      │
      ▼
剩余 95% 按阶梯分配
      │
      ├── 🥇 35% × 0.95 = 33.25%
      ├── 🥈 25% × 0.95 = 23.75%
      ├── 🥉 18% × 0.95 = 17.10%
      ├── 第4-5 15% × 0.95 = 14.25%（两人均分，各 7.125%）
      ├── 第6 7% × 0.95 = 6.65%
      └── 💀 第7 0%
      │
      ▼
DEMO：服务端记录，展示"TAO 模拟值"
正式版：RewardDistributor 合约执行 TAO 转账
```

### 8.3 持续收益——声誉 NFT 质押减免

正式版中，游戏历史表现被铸造成链上 `ReputationNFT`。该 NFT 的核心经济功能：

| NFT Stage | 诚实率 | 质押减免 | 对应游戏表现 |
|-----------|--------|---------|------------|
| 1-3 | ≥ 60% | 10% | 新人/普通玩家 |
| 4-6 | ≥ 80% | 20% | 稳定进入前 5 |
| 7-9 | ≥ 90% | 30% | 频繁冠军/亚军 |
| 10 | ≥ 95% | 40% | 顶级玩家 |

**持有高 Stage NFT 的玩家，下一局入场质押自动减免**——"你的历史信誉让你的入场成本更低"。这直接激励玩家长期认真博弈。

### 8.4 与技术方案的映射

| 收益系统 | Bittensor 子网对应 |
|---------|------------------|
| 入场质押（0.05 TAO） | `StakingRegistry.registerMiner/Validator()` 质押 |
| 收益池（0.35 + 外部注入） | Epoch 奖励池 |
| 阶梯分账 | `RewardDistributor.distributeEpochRewards()` |
| 国库协议费 5% | 子网国库收入（用于安全审计 + 生态基金） |
| 声誉 NFT 质押减免 | `calculateStakeDiscount(tokenId)` → 最高 30% |
| 外部 API 注入 | 跨子网 `CrossSubnetGateway` 收入 → 部分回流游戏 |

## 十、特殊机制详解

### 10.1 叛徒与收编契约

叛徒基金 6 筹码（系统管理）。状态机：

```
Normal ──(贿赂+任务)──→ Contracted
                          ├── 完成 → 双方各 +2（基金支出）
                          ├── 拒绝 → 罚 2 给叛徒，回 Normal
                          └── 反叛揭露 → 叛徒罚 5 + 公开，揭露者罚 3

Normal ──(自身为叛徒)──→ Traitor
                          └── 被揭露 → 罚 5 + 公开（已有契约继续有效）
```

### 10.2 在线匿名交易

- 交易阶段开放聊天面板（公共 + 私有消息）
- 叛徒契约通过系统表单发起
- 脱离 / 揭露为系统按钮 → 立即执行 + 广播

### 10.3 系统自动化

| 阶段 | 倒计时 | 超时默认 |
|------|--------|---------|
| 矿工声明 | 120 秒 | 系统随机声明 |
| 验证者评分+举报 | 180 秒 | 系统随机打分（非全员同分） |
| 所有者审计 | 120 秒 | 跳过审计 |
| 匿名交易 | 120 秒 | 关闭交易 |
| 深度审计 | 120 秒 | 跳过 |
| 合约投票 | 90 秒 | 默认"反对" |
